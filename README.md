\# AI Course Assistant: End-to-End Generative AI PDF Chatbot ## 1\. Problem Statement &amp; User Persona \* \*\*Problem Statement:\*\* Students enrolled in AI courses often struggle to quickly locate specific administrative policies, assignment rubrics, and grading criteria buried across multi-page syllabi and PDF policy documents [1-3]. Manually searching documents or waiting for email replies creates delays. This project provides a Retrieval-Augmented Generation (RAG) AI chatbot that delivers instant, 24/7 answers strictly grounded in official course materials [1, 4, 5]. \* \*\*User Persona:\*\* \*\*Alex\*\*, a 3rd-year student juggling multiple modules who needs instant clarity on assignment deadlines, late submission policies, and allowed AI tool usage without waiting for TA office hours [3, 6]. ## 2\. System Prompt &amp; Guardrails The system prompt enforces strict context-grounding to avoid AI hallucinations [1, 4, 7]: &gt; \*"You are a helpful Teaching Assistant for this AI course. Answer questions based ONLY on the provided context from the PDF syllabus. If the answer is not present in the document, respond with: 'I don't know based on the provided document.' Do not guess or hallucinate."\* [4, 8-10] ## 3\. Critical Reflection (Model Strengths &amp; Limitations) \* \*\*Strengths:\*\* - \*\*Zero Hallucination:\*\* Constrains answers strictly to provided course documents [1, 4, 9]. - \*\*Rapid Search:\*\* Replaces manual document scanning with semantic vector search [1, 11, 12]. - \*\*Interactive UI:\*\* Built using Streamlit for clean drag-and-drop file interaction [5, 13, 14]. \* \*\*Limitations:\*\* - \*\*Context Window Limits:\*\* Large files require chunking and vector storage to fit within model limits [11, 15, 16]. - \*\*Information Boundary:\*\* Cannot answer questions outside the uploaded document [4, 9].
